# Bonds & Nodes

This repository is the computational companion to my Substack publication.

The articles focus on explaining chemistry from first principles through mathematics, programming, and visualization. This repository contains the code that brings those ideas to life.

Rather than treating computation as a black box, every notebook is written to be explored, modified, and experimented with. My hope is that readers leave not only understanding *what* the computation does, but also *why* it works.

---

## Philosophy

Chemistry is often taught as a collection of facts and theories.

I personally believe it becomes much more intuitive when we rebuild it from its mathematical foundations.

Every notebook in this repository follows the same philosophy:

- Represent molecules as mathematical objects.
- Build computational models step by step.
- Visualize every important concept.
- Encourage experimentation instead of memorization.

If changing one line of code teaches more than reading one extra paragraph, then the notebook has done its job.

# Getting Started

You can either:

## Option 1: Google Colab (Recommended)

Open the notebook directly in your browser without installing anything.

Every notebook includes installation steps for any required dependencies.

---

## Option 2: Local Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/bonds-and-nodes-labs.git
```

Move into the repository

```bash
cd bonds-and-nodes-labs
```

Install the required packages

```bash
pip install -r requirements.txt
```

Launch Jupyter Notebook or open the notebooks in VS Code.
